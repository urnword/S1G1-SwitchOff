# 📸 Media — Switch Off!!!

This folder contains visual assets for the Switch Off!!! project.

## Contents

| File | Description |
|---|---|
| `dashboard.png` | Screenshot of the web dashboard (main menu + control panel) |
| `prototype.png` | Physical prototype mounted on a wall switch |
| `circuit_diagram.jpg` | Full wiring diagram exported from Cirkit Designer |
| `demo.mp4` | Short video demonstrating the full system |

## Dashboard Preview

The web interface (Next.js + Firebase) provides:
- Device list with live status summary
- Detailed control panel per device
- Real-time status: Device Online/Offline, Switch state, Light, Fan, Presence
- Manual Turn On / Turn Off controls
- Auto-Off configuration toggle

Live: [https://studio--switch-off-b68c4.us-central1.hosted.app/](https://studio--switch-off-b68c4.us-central1.hosted.app/)

## Adding Media Files

When uploading to GitHub, place files directly in this folder:
```
docs/media/
├── dashboard.png
├── prototype.jpg
├── circuit_diagram.jpg
└── demo.mp4
```

Then reference them in the main README with:
```markdown
![Dashboard](docs/media/dashboard.png)
```
